# Provider submission checklist

Please return this checklist with the real sample package.

## Required submission

- [ ] Authorization letter or project-use license
- [ ] `metadata/dataset_inventory.csv` completed
- [ ] `metadata/crs_and_units.yaml` completed
- [ ] `metadata/field_dictionary.csv` completed
- [ ] `metadata/mapping_rules.yaml` completed
- [ ] Boundary file
- [ ] DEM and DEM metadata
- [ ] Building footprints and stable IDs
- [ ] Land-cover/surface classes and parameter mapping
- [ ] SWMM `.inp` and all referenced files
- [ ] Surface/inlet-to-SWMM mapping
- [ ] Roof/drain-to-SWMM mapping
- [ ] Expected-output or acceptance reference

- [ ] D-Flow FM version/build declaration
- [ ] Native boundary mapping and direction/type declaration
- [ ] Surface-to-river mapping
