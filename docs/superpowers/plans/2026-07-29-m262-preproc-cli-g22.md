# M262 PreProc CLI + G22 File-Driven Mixed Mesh Plan

Date: 2026-07-29
Base: master `5e450b4`

## Goal

Land the first executable PreProc path and a persistent-file Golden that
exercises the complete chain:

`scau_preproc -> .stcf.nc -> strict UGRID read -> mesh/DPM/source/z_b load -> Surface2D advance`.

## Design

- `libs/stcf/case_profiles.*` owns deterministic authored case construction.
  Initial profile: `mixed-minimal`, a 2-face quad+triangle mesh with varying
  `phi_t`/SPD `Phi_c`, nonzero Manning roughness, sloping bed, and explicit
  edge conveyance. It passes the same export validation as any future import.
- `apps/preproc_cli` executable `scau_preproc` parses:
  `scau_preproc generate --profile mixed-minimal --output <case.stcf.nc>`.
  It rejects unknown/missing/duplicate arguments and existing output unless
  `--force` is supplied. It writes atomically via `<output>.tmp` + rename so
  failed generation never leaves a partial case.
- No JSON/YAML/GIS input schema is invented in this slice. Future import
  subcommands will feed the same `StcfCase` validation/export boundary.
- G22 `preproc_mixed_mesh_case` invokes the built CLI as a CTest fixture setup,
  then the Golden test loads the persistent output file through
  `load_surface2d_case(path)`.

## G22 assertions

- expected 5 nodes / 2 faces / 6 edges and mixed cell types;
- file-carried fields match profile constants;
- 20-step varying-phi_t/sloping-bed lake at rest stays within 1e-12;
- 10-step DischargeInflow volume gain equals q*L*dt*N within 1e-12;
- generated file is deterministic at the logical data level: a second
  generation is loaded and all topology/field arrays compare exactly.

G19/G20 remain reserved for the post-G18 coupling completion line; this slice
uses G22.
